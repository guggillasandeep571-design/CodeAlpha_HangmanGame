# Hangman Game

## Description
A text-based word guessing game developed using Python.

## Features
- Randomly selects a word from five predefined words.
- Allows the player to guess one letter at a time.
- Allows a maximum of six incorrect guesses.
- Displays win or game-over messages.

## Requirements
- Python 3

## How to Run
Open the terminal in this folder and run:

```bash
python hangman.py
```
